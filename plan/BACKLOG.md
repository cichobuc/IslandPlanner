# Backlog (nápady mimo v1)

## Pravdepodobne v2
- Sledovanie reálnych výdavkov počas cesty vs. plán (učenie odhadov), vyrovnanie medzi členmi s transakciami.
- Supabase Realtime namiesto optimistic concurrency.
- Supabase Realtime – živé úpravy viacerých členov naraz (kurzory, prezencia).
- „Kto platil" a vyrovnanie medzi cestujúcimi (Splitwise-like).
- GetYourGuide / Viator affiliate API na živé ceny túr.
- Parkos / ParkVia API na parkovanie pri letiskách.
- Scraping ponúk karavanov (Playwright na vlastnom serveri, nie Vercel).
- Kiwi Tequila (ak sa otvorí) pre virtual interlining.
- Push notifikácie (Web Push v Safari 16.4+ pre PWA).
- Návrhy opráv seed dát od používateľov s moderáciou.
- Polárna žiara: KP index (NOAA) + oblačnosť → „šanca dnes večer" v itinerári.
- Balenie: checklist podľa aktivít (ľadovec → mačky, kúpele → plavky, dron → ND filtre).
- Rozdelenie skupiny na časť dňa (2 idú na ľadovec, 2 do kúpeľov) – dve vetvy dňa.
